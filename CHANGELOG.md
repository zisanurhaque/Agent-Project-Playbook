# Changelog

Meaningful changes to this repository. Entries are grouped by date; versions are not tagged yet.

## 2026-10-09

### Added

- Initial repository structure: `README.md`, `AGENTS.md`, `CONTRIBUTING.md`, and this changelog.
- Eight prompts in `prompts/`, with an index and shared conventions in `prompts/README.md`.
- Three workflows in `workflows/`: `start-a-project.md`, `improve-an-existing-project.md`, and `document-and-present-a-project.md`.
- A fictional illustrative example in `examples/illustrative-project/` containing a project brief, a decision record, a handoff, and a case-study excerpt.

### Notes

- All prompts and workflows are `Draft`. None has been exercised on a real task, so no validation status is higher than `Draft`.
- No license has been selected. License choice is an owner decision and should be made before the repository is treated as released or open source.
- The repository was created in an empty directory that was not under version control, so there was no prior content to preserve.
- `prompts/06-project-documentation.md` is adapted from the repository author's own project-documentation prompt, preserving its safeguards and reorganising it into the shared prompt format.
- That source prompt is still at the repository root as `project-documentation-prompt.md`. It now overlaps with the prompt derived from it, so keeping, archiving, or removing it is an open owner decision.
